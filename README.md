🎮 Game Project (C++)

A simple game developed in C++, focused on learning core game development concepts such as game loops, input handling, rendering, and object management.

🚀 Features

Built using modern C++

Real-time game loop

Player movement system

Basic collision detection

Simple gameplay mechanics

Lightweight and fast execution

🛠️ Requirements

Make sure you have the following installed:

C++17 or later

GCC / Clang / MSVC compiler

📦 Installation & Running
1. Clone the repository
git clone https://github.com/souhahamami-ship-it/game-.git
cd game-
2. Compile the project
Using g++
g++ main.cpp -o game

3. Run the game
./game
🎮 Controls
Key	Action
W / A / S / D	Move

🧠 Concepts Used

Object-Oriented Programming (OOP)

Game loop architecture

Event handling
